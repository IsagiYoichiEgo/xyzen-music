# XYZEN Music

A dark, glassy music player concept. Tracks are generated live in the browser with the Web Audio API, and the ring visualizer reacts to the real audio signal.

**Live:** https://isagiyoichiego.github.io/xyzen-music/

- Four mood playlists, each with its own tempo and palette
- Inertia cursor, glassmorphism UI, scroll reveals
- Plain HTML, CSS and JavaScript in a single file, no build step

Artists and tracks are fictional. Concept by [alimbro](https://isagiyoichiego.github.io/resume-react/).
